# Site de Agendamento FETEC

Modelo responsivo em HTML, CSS e JavaScript puro.

## Estrutura
- index.html
- css/style.css
- js/app.js
- assets/

## Recursos
- Layout responsivo
- Menu mobile
- Seleção de serviço
- Data e horários
- Formulário de agendamento
- Máscara de WhatsApp
- Modal de confirmação
- LocalStorage para demonstração

Abra `index.html` no navegador. Para produção, conecte o formulário a uma API/banco de dados e a serviços como WhatsApp, e-mail, calendário ou pagamentos.
